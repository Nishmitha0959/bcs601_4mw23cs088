## Project Description
This project is a simple factorial calculator web application developed using Python Flask framework. The user enters a number and the application calculates and displays the factorial of the entered number.

## Features
- User can enter any number
- Calculates factorial instantly
- Attractive web interface
- Cloud deployed application
